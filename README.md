# E-commerce Dash

Dashboard interativo desenvolvido como projeto final do Módulo 23 do curso de Analista de Dados da EBAC.

## Sobre o projeto

O projeto tem como objetivo transformar a análise estatística dos dados de um e-commerce em uma aplicação web interativa, permitindo que o usuário explore os principais resultados sem precisar executar diretamente o código Python.

A aplicação foi desenvolvida utilizando Dash e Plotly, com os dados tratados e analisados utilizando Pandas.

## Tecnologias utilizadas

- Python
- Pandas
- Plotly
- Dash
- Statsmodels

## Visualizações

O dashboard apresenta diferentes visualizações dos dados:

- Histograma
- Gráfico de dispersão
- Mapa de calor de correlações
- Gráfico de barras
- Gráfico de pizza
- Gráfico de densidade
- Gráfico de regressão linear

## Principais análises

Entre os principais insights identificados na análise está a forte relação entre o número de avaliações e a quantidade de produtos vendidos.

O dashboard permite visualizar essas relações de forma interativa, facilitando a interpretação dos dados e a identificação de padrões.
